# LéoN NoèL — Combined Author Website

This build combines the cleaner author-brand structure of the first archive with the richer catalog, book-detail content, and downloadable resources from the second.

## What changed
- Retained the clean three-collection homepage and navigation.
- Added a focused “good places to begin” book strip to the homepage.
- Added a stronger author introduction before the newsletter.
- Added individual detail pages for Yok, Bilingual Yok, and Blue Dreams Forest books.
- Added local companion PDF downloads under `assets/downloads/`.
- Added “Book details” links throughout the catalogs.
- Kept the existing release calendar, resource library, about page, SEO files, and social/contact links.

## Deploy
Upload the contents of this folder to the root of a static host or GitHub Pages repository. `index.html` is the entry point.
