This archive is ready for the repository:

`https://github.com/leonnoelauthor/yokstories-site`

The published address is:

`https://leonnoelauthor.github.io/yokstories-site/`

## Replace the existing site

1. Back up or create a branch from the existing repository.
2. Copy everything in this archive to the repository root.
3. Commit and push to `main`.
4. In **Settings → Pages**, select **Deploy from a branch**, then `main` and `/ (root)`.

The package includes `index.html`, all section pages, optimized images,
`.nojekyll`, social links, canonical metadata, and paths configured for the
`/yokstories-site/` repository URL.
